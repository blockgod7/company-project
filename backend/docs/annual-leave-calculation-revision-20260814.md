# 연차 계산식 개정 최종 명세

## 1. 목적과 기준

- 이 문서는 2026-08-14 딥인터뷰에서 확정한 연차 자동 계산 및 2026년 데이터 적용 기준이다.
- 연차 기준연도는 매년 1월 1일부터 12월 31일까지다.
- `2026년 연차안내.xlsx`의 2026년 확정값과 사용자가 별도로 확인한 예외값을 2026년 기존 직원의 기준 데이터로 사용한다.
- 출결 시스템 연동 전에는 재직 기간을 모두 출근한 것으로 간주한다.
- 출근율 및 비례 계산의 분모는 윤년에도 365일로 고정한다.
- 연차 계산과 사용량 차감에는 결재 완료(`APPROVED`) 문서만 반영한다. 결재 대기, 반려, 취소 문서는 포함하지 않는다.

## 2. 입사 당해 임시 연차

입사 당해에는 입사 후 한 달 전체를 근무하는 달의 수만큼 임시 연차를 지급한다.

- 매월 1일 입사자는 해당 월을 포함한다.
- 매월 2일 이후 입사자는 다음 달부터 포함한다.
- 계산 결과는 정수 일수다.

예시:

| 입사일 | 포함 월 | 지급 일수 |
| --- | --- | ---: |
| 2026-04-01 | 4월~12월 | 9일 |
| 2026-04-02 | 5월~12월 | 8일 |
| 2026-04-23 | 5월~12월 | 8일 |

## 3. 입사 다음 해 연차

### 3.1 출근 인정 일수

- 입사일부터 입사 연도 12월 31일까지를 양 끝 날짜를 포함하여 계산한다.
- 출결 시스템 연동 전에는 위 재직 일수 전체를 출근 일수로 인정한다.
- 출근율 판정은 반올림하기 전의 정확한 `출근 인정 일수 / 365` 값으로 한다.

### 3.2 기본 연차

- 출근율이 80% 이상이면 15일을 지급한다.
- 출근율이 80% 미만이면 `15 × 출근 인정 일수 ÷ 365`로 계산한다.
- 비례 계산 결과는 0.5일 단위로 항상 올림한다.

올림 예시:

| 원 계산값 | 지급값 |
| ---: | ---: |
| 5.01 | 5.5일 |
| 5.22 | 5.5일 |
| 5.50 | 5.5일 |
| 5.51 | 6일 |

### 3.3 가산 및 차감

- 입사 다음 해에는 가산 연차 11일을 더한다.
- 입사 당해에 실제 사용한 연차 중 결재 완료된 사용분만 차감한다.
- 결재 완료된 휴가 취소가 있으면 취소된 사용분은 차감 대상에서 제거한다.
- 결과의 최솟값은 0일, 최댓값은 30일이다.

최종식:

```text
입사 다음 해 연차
= 기본 연차(15일 또는 비례 연차)
+ 11일
- 입사 당해 결재 완료 사용분
```

예시:

```text
출근 인정 일수 164일, 전년도 승인 사용분 3일
기본 연차 = 15 × 164 ÷ 365 = 6.739... → 0.5일 단위 올림 7일
최종 연차 = 7 + 11 - 3 = 15일
```

## 4. 이후 근속 연차

입사 다음 해의 특별 계산을 마친 뒤 1년을 풀근무한 다음 연도부터 근속 가산을 시작한다.

```text
가산 기준연수 = max(0, 대상연도 - 입사연도 - 2)

가산 기준연수 0~10:
  연차 = 15 + 가산 기준연수

가산 기준연수 11 이상:
  연차 = 25 + floor((가산 기준연수 - 10) / 2)

최대 연차 = 30일
```

- 15일부터 25일까지는 1년에 1일씩 증가한다.
- 25일에 도달한 뒤에는 2년에 1일씩 증가한다.
- 최대 30일을 초과하지 않는다.
- 입사 첫해의 출근율은 입사 다음 해 특별 계산에만 사용하고, 이후 근속 가산을 한 해 늦추는 조건으로 사용하지 않는다.

2026년 예시:

| 입사연도 | 2026년 근속 연차 |
| ---: | ---: |
| 2024 | 15일 |
| 2023 | 16일 |
| 2022 | 17일 |
| 2014 | 25일 |
| 2013 | 25일 |
| 2012 | 26일 |

## 5. 계약직 처리

- 계약직의 연차 지급량은 근속연수와 관계없이 15일이다.
- 계약직의 승인 완료 사용량은 지급량을 바꾸지 않고 별도의 사용량 및 잔여량으로 관리한다.
- 직원관리 화면에서 관리자가 고용형태를 `정규직(REGULAR)`에서 `계약직(CONTRACT)`으로 전환할 때 계약 시작일과 계약 종료일을 필수로 입력한다.
- 계약 기간을 임의로 추정하거나 자동 생성하지 않는다.

정년 후 계약직으로 확인된 직원:

- 고형모: 15일
- 양영순: 15일
- 양효석: 15일
- 손정룡: 15일

계약 기간이 입력되기 전에는 위 직원의 2026년 확정 연차 15일을 보존한다.

## 6. 직원 기준정보 정정

| 직원 | 확정 기준정보 |
| --- | --- |
| 이정민 | 입사일 2016-09-01, 2026년 연차 23일 |
| 김진일 | 입사일 2024-01-15 |
| 양영순 | 원래 입사일 1997-09-29 유지. 2024-05-01은 계산 기준일이나 재입사일로 사용하지 않음 |

## 7. 2026년 적용 및 이관 범위

- 엑셀과 DB에서 직원명이 대응되는 기존 직원 138명의 2026년 확정 연차는 그대로 보존한다.
- 위 138명은 사용자 확인 예외를 반영하면 엑셀 기준값과 DB 값이 모두 일치한다.
- 기존 2026년 연차를 새 계산식으로 일괄 덮어쓰지 않는다.
- 엑셀에 없고 DB에만 있는 2026년 신규 입사자 13명만 입사 당해 계산식으로 재계산한다.
- 엑셀에만 있는 10명은 이번 작업에서 직원 DB에 자동 생성하거나 연차를 이관하지 않는다.
- 관리자 수동 확정(`MANUAL`) 데이터는 자동 재계산으로 덮어쓰지 않는다.
- 자동 재계산 전후 값과 계산 근거는 연차 원장에 남긴다.

## 8. 구현 경계

이번 개정에 포함한다.

- 입사 당해 월수 계산에서 매월 1일 입사자 월 포함
- 입사 다음 해 80% 판정, 365일 고정 분모, 0.5일 단위 올림
- 입사 다음 해 `기본 + 11 - 전년도 승인 사용분` 계산
- 25일까지 매년 증가하고 이후 2년마다 증가하는 최대 30일 근속식
- 결재 완료 사용분만 조회하는 계산 경계
- 계약직 15일 처리와 직원관리의 계약 기간 필수 입력
- 확정된 직원 기준정보 정정
- 2026년 신규 입사자 13명 재계산
- 계산 단위 테스트와 데이터 적용 전후 검증

이번 개정에 포함하지 않는다.

- 실제 출퇴근 기록을 수집하는 출결 시스템 연동
- 엑셀에만 존재하는 직원 10명의 자동 등록
- 결재 대기 또는 반려 문서의 사용량 차감
- 기존 확정 연차 138명의 일괄 재계산
- 계약 시작일 또는 종료일의 임의 추정

## 9. 완료 조건

- 입사 당해 1일 입사와 2일 이후 입사의 월수 경계 테스트가 통과한다.
- 입사 다음 해 80% 경계, 365일 분모, 0.5일 올림 테스트가 통과한다.
- 승인 완료, 대기, 반려, 승인 취소 문서별 사용량 차감 테스트가 통과한다.
- 15일에서 25일까지 매년 증가하고 25일 이후 2년마다 증가하며 30일에서 멈추는 테스트가 통과한다.
- 계약직은 15일로 계산되고 계약 전환 시 기간 누락을 저장할 수 없다.
- 이정민, 김진일, 양영순의 기준정보가 확정값과 일치한다.
- 기존 대응 직원 138명의 2026년 연차는 변경되지 않는다.
- 신규 입사자 13명만 새 계산값으로 반영된다.
- 백엔드 테스트와 관련 프런트엔드 빌드가 통과한다.
- 데이터 적용 전후의 직원별 연차 비교 결과를 검증할 수 있다.
