# 휴가계 및 휴가 취소계 사용 설명서

- 대상: 그룹웨어 전자결재 사용자 및 휴가 운영 관리자
- 메뉴: `전자결재`
- 사용 양식: `휴가계(LEAVE)`, `휴가 취소계(LEAVE_CANCEL)`
- 최종 확인일: 2026-08-11

## 1. 빠른 사용 순서

### 휴가 신청

1. `전자결재`에서 `작성`을 누른다.
2. 양식 선택 창의 `2. 휴가, 출장`에서 `휴가계`를 선택하고 `확인`을 누른다.
3. 달력에서 신청 날짜를 누르고 날짜별 휴가 종류를 선택한다.
4. 상단 `결재 정보 수정`에서 결재자와 수신자를 확인한다.
5. 필요하면 첨부파일을 추가하고 `미리보기`로 내용을 확인한다.
6. 작성 중이면 `임시저장`, 결재를 시작하려면 `상신`을 누른다.

### 승인된 휴가 취소

1. `전자결재`에서 `작성`을 누른다.
2. `휴가 취소계`를 선택하고 `확인`을 누른다.
3. 달력에 표시된 승인 완료 휴가 중 취소할 항목을 선택한다.
4. 결재 정보와 수신자를 확인한 뒤 `상신`한다.
5. 취소계가 최종 승인되면 취소 대상의 일반 연차 사용분이 복원된다.

## 2. 휴가계 작성 방법

### 2.1 기본 정보 확인

작성 화면에는 신청자, 부서, 신청일과 다음 휴가 현황이 표시된다.

- `총 휴가 일수`: 해당 연도의 확정 휴가 일수
- `신청 전 휴가 사용 일수`: 최종 결재 완료 문서를 기준으로 계산한 사용량
- `이번 신청 휴가 일수`: 현재 문서에서 선택한 휴가 일수
- `신청 후 연차 잔여`: 현재 선택을 반영한 예상 잔여일수

휴가계 화면에는 문서 제목 입력란이 없다. 시스템 내부에서는 목록·검색·PDF 구분을 위해 양식명이 자동 사용되며, 문서번호는 상신할 때 자동 생성된다.

### 2.2 날짜와 휴가 종류 선택

1. 달력의 `이전` 또는 `다음`으로 신청 월을 찾는다.
2. 신청할 날짜를 누른다.
3. 선택된 날짜 안의 목록에서 휴가 종류를 고른다.
4. 여러 날짜가 필요하면 같은 방식으로 추가한다.
5. 선택을 해제하려면 선택된 날짜를 다시 누른다.

날짜 선택 규칙은 다음과 같다.

- 주말과 등록된 휴일은 선택할 수 없다.
- 이미 종일 휴가가 있는 날짜는 다시 선택할 수 없다.
- 오전반차가 있으면 오후반차 또는 공가(오후), 오후반차가 있으면 오전반차 또는 공가(오전)를 추가할 수 있다.
- 한 문서에는 같은 연도의 날짜만 선택할 수 있다. 연도가 다르면 문서를 나누어 작성한다.
- 연차와 하계휴가는 1일, 오전·오후반차는 0.5일로 일반 연차에서 계산된다.
- 연차를 차감하지 않는 휴가 종류는 화면의 정책 표시와 상세 입력 항목을 따른다.

휴가 종류 선택 목록은 연차, 오전반차, 오후반차가 가장 먼저 나오고, 이후 조퇴, 하계휴가, 공가, 경조, 대체휴무, 병가, 공상, 산재요양, 무급휴가, 출산 관련 휴가와 육아휴직 등이 표시된다. 자녀돌봄휴가, 특별유급휴가, 가족돌봄휴가는 신규 신청에서 제외되며 과거 문서 이력만 보존한다.

### 2.3 휴가 종류별 추가 입력

휴가 종류를 선택하면 필요한 항목만 `선택 날짜 상세`에 나타난다.

| 휴가 종류 | 확인 또는 입력 항목 |
|---|---|
| 무급휴가 | 구체적인 신청 사유. 결재 중 예약분을 반영한 잔여연차가 10일 미만인 직원만 신청 가능 |
| 공가 | 구체적인 신청 사유 |
| 병가 | 무급·연차 미차감. 달력 기준 연속 14일 이상이며 진단서 첨부 필수 |
| 난임치료휴가 | 난임치료 관련 서류 첨부 필수 |
| 조퇴 | 시작시간 필수. 관리직은 유급, 현장직은 무급이며 모두 연차 미차감 |
| 공상 | 유급·연차 미차감. 구체적인 신청 사유 필수 |
| 경조 | 경조 유형, 대상 관계(사망은 상신자와 고인의 관계), 허용일수와 증빙 필요 여부 |
| 산재요양 | 예상 휴업 시작·종료일, 산재 접수정보 |
| 배우자 출산휴가, 출산전후휴가 | 출산 예정일, 실제 출산일. 배우자 출산휴가는 기본 20일, 다태아 25일 |
| 대체휴무 | 사용 가능 적립일수와 결재 중 예약일수. 발생 연도 12월 31일까지 사용하고 다음 해 1월 1일 잔여분 만료 |

법정 한도나 사내 정책이 있는 휴가는 상신할 때 서버에서 다시 검사한다. 화면에서 안내한 한도를 넘으면 휴가관리자에게 확인한다.

### 2.4 결재자와 수신자 확인

상단의 `결재 정보 수정`을 누르면 결재선과 수신자를 변경할 수 있다.

- 결재자는 상신 전에 1명 이상 지정해야 한다.
- 기안자 본인은 합의자 또는 결재자로 지정할 수 없다.
- 합의자, 결재자, 수신자는 서로 중복 지정할 수 없다.
- 휴가 문서 수신자는 1명만 지정할 수 있다.
- 기본 수신자는 운영 설정에 따라 자동 지정된다. 초기 운영 기본값은 인사총무 `허인성 대리`이다.
- 자동 지정된 수신자는 삭제하거나 다른 활성 직원 1명으로 교체할 수 있다.

변경 후 결재 정보 창의 `적용`을 눌러야 작성 화면에 반영된다.

### 2.5 첨부, 미리보기, 저장과 상신

- `첨부파일`: 저장 전에 필요한 파일을 선택한다.
- 병가, 난임치료휴가 등 증빙 필수 휴가는 화면에 필요한 서류가 표시된다. 시스템은 파일 내용을 판독하지 않고 첨부파일이 한 개 이상 존재하는지만 확인한다.
- `미리보기`: 현재 입력값을 읽기 전용 형태로 확인한다. 미리보기만으로 문서는 저장되지 않는다.
- `임시저장`: 작성 중인 내용을 보관한다. 결재는 시작되지 않는다.
- `상신`: 입력값과 결재선을 검증한 뒤 결재를 시작한다.

결재 중인 휴가 예약분까지 포함해 잔여일수를 초과하면 상신 버튼이 비활성화되거나 오류가 표시될 수 있다. 이 경우 진행 중 문서를 회수하거나 휴가관리자에게 잔여일수를 확인한다.

## 3. 휴가 취소계 작성 방법

### 3.1 취소할 휴가 선택

휴가 취소계 달력에는 현재 사용자가 최종 승인받은 휴가만 선택 항목으로 표시된다.

1. `이전` 또는 `다음`으로 원본 휴가가 있는 월을 찾는다.
2. `기존 연차`, `기존 오전반차`처럼 표시된 항목을 누른다.
3. 선택되면 `취소 연차`, `취소 오전반차`처럼 표시가 바뀐다.
4. 다시 누르면 선택이 해제된다.

각 항목 아래에는 가능하면 원본 휴가 문서번호가 표시된다. 같은 날짜에 오전반차와 오후반차가 모두 있으면 각각 별도 항목으로 선택할 수 있다.

### 3.2 선택 제한

- 승인 완료되지 않은 휴가는 취소 대상으로 나타나지 않는다.
- 이미 다른 취소계에서 처리 중인 항목은 `취소 결재 중`으로 표시되며 선택할 수 없다.
- 같은 취소계에는 같은 연도의 항목만 담을 수 있다.
- 과거 연도의 휴가를 선택하면 해당 연도의 휴가 잔여정보를 다시 조회한다.
- 원본 휴가 문서와 신청자, 날짜, 휴가 종류가 일치하지 않으면 저장 또는 상신할 수 없다.

### 3.3 복원 일수 확인

화면 하단에서 다음 값을 확인한다.

- 선택한 취소 건수
- 취소하는 실제 휴가 일수
- 취소 승인 후 복원되는 일반 연차 일수

공가, 경조, 대체휴무처럼 일반 연차를 차감하지 않은 항목은 취소 일수에는 포함될 수 있지만 일반 연차 복원량은 0일일 수 있다.

취소계가 최종 승인된 뒤에만 복원이 확정된다. 취소계를 임시저장하거나 상신한 상태만으로는 원본 휴가 사용량이 복원되지 않는다.

## 4. 상신 후 처리

- 작성자는 전자결재의 신청 문서 목록에서 처리 상태와 결재 진행상황을 확인한다.
- 첫 합의·결재 처리가 시작되기 전에는 권한이 표시되는 경우 `회수`할 수 있다.
- 회수한 문서는 내용을 수정한 뒤 다시 상신할 수 있다.
- 반려된 문서는 `재상신` 기능으로 수정본을 작성할 수 있다.
- 승인된 휴가계는 휴가 사용량에 반영된다.
- 승인된 휴가 취소계는 연결된 원본 휴가 항목을 취소하고 해당 차감분을 복원한다.

버튼은 현재 문서 상태와 사용자 권한에 따라 표시되지 않을 수 있다.

## 5. 자주 발생하는 메시지

| 메시지 또는 상황 | 확인할 내용 |
|---|---|
| 휴가 문서 수신자를 1명 지정해 주세요. | `결재 정보 수정`에서 활성 직원 1명을 수신자로 지정한다. |
| 상신 전 결재자를 1명 이상 선택해 주세요. | 결재자를 한 명 이상 추가한다. |
| 합의자, 결재자, 수신자는 중복 지정할 수 없습니다. | 같은 직원을 여러 역할에 넣지 않았는지 확인한다. |
| 총 휴가 일수를 초과합니다. | 결재 중 예약분과 현재 신청량을 확인하고 휴가관리자에게 문의한다. |
| 대체휴무 잔여가 부족합니다. | 대체근무 적립 및 예약일수를 확인한다. |
| 취소 결재 중 | 동일 원본 휴가에 대한 다른 취소계가 완료될 때까지 기다리거나 기존 문서를 확인한다. |
| 휴가 기본 수신자 설정을 찾지 못했습니다. | 수신자를 직접 지정하고 관리자에게 운영 설정을 확인해 달라고 요청한다. |

## 6. 상신 전 확인표

- [ ] 신청 또는 취소 날짜가 맞다.
- [ ] 날짜별 휴가 종류가 맞다.
- [ ] 사용·복원 일수와 예상 잔여일수를 확인했다.
- [ ] 휴가 종류별 추가 입력을 완료했다.
- [ ] 결재자가 1명 이상 지정되어 있다.
- [ ] 수신자가 정확히 1명 지정되어 있다.
- [ ] 필요한 증빙파일을 첨부했다.
- [ ] 미리보기에서 최종 내용을 확인했다.

## 7. 관리자 운영 안내

### 7.1 휴가 기본 수신자

전자결재 관리자(`ADMIN` 또는 `APPROVAL_ADMIN`)는 `전자결재 > 운영설정`에서 `휴가 기본 수신자`를 변경할 수 있다.

1. `휴가 기본 수신자`의 `선택`을 누른다.
2. 활성 직원 한 명을 선택하고 `적용`을 누른다.
3. 운영설정 화면의 `저장`을 누른다.

변경한 값은 이후 새로 작성하는 휴가계와 휴가 취소계에 적용된다. 사용자는 문서별로 다른 수신자로 교체할 수 있다.

### 7.2 경조휴가 기준

경조휴가는 모두 평일 기준 유급휴가로 계산한다.

- 결혼: 본인 5일, 자녀 1일
- 사망: 조부모·형제자매 2일, 배우자·부모·배우자 부모·자녀 5일
- 출산: 경조휴가에서 제외하며 배우자 출산휴가·출산전후휴가 등 전용 휴가를 사용한다.

신청자는 `경조 유형`에서 `사망`을 선택한 뒤 `상신자와 고인의 관계`를 선택한다.

휴가관리자는 `전자결재 > 휴가정책 > 경조 유형·관계별 기준표`에서 해당 행의 `수정`을 눌러 허용일수, 유·무급, 증빙 필수 여부, 시행기간 및 사용 여부를 변경할 수 있다. 수정할 때는 변경 사유를 반드시 입력한다.

### 7.3 휴가 운영 데이터

휴가관리자는 다음 항목을 정기적으로 확인한다.

- 직원별 확정 연차와 사용량
- 활성 휴가정책과 경조휴가 기준
- 법정공휴일 및 사내 휴일
- 대체휴무 적립·사용·만료 내역
- 자동 작업 실패 여부
- 승인 휴가의 관리자 제외 또는 취소 내역

구형 휴가 취소계의 원본 문서 연결 상태는 저장소 루트에서 다음 명령으로 확인한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-local-db.ps1 -SkipBackendHealth -SkipSeedCheck
```

검증 결과에서 다음 항목이 모두 `[OK]`여야 한다.

- `leave cancellation selections have source approval ids`
- `leave cancellation source approval references are valid`
- `leave default receiver setting resolves to an active employee`

운영 DB의 비밀번호나 접속정보를 문서 또는 명령 이력에 저장하지 않는다.

### 7.4 관리자 권한과 직군

- 시스템관리자는 변경하거나 회수할 수 없는 최상위 권한자다.
- 전권 관리자는 여러 명에게 부여할 수 있으며 전권·개별 권한을 다른 직원에게 부여하거나 회수할 수 있다.
- 초기 전권 관리자는 임정식 부장이다. 퇴직 처리 시 보유 권한은 자동 회수되며 다른 직원에게 다시 부여할 수 있다.
- 허인성 대리는 초기 `직군관리` 권한을 보유하며 나머지는 부여받은 권한만 사용한다.
- 개별 권한은 휴가관리, 휴가정책관리, 직원관리, 직군관리, 계정관리로 나뉜다.
- 직군관리 권한자는 직원별 `관리직` 또는 `현장직`을 지정한다. 조퇴의 유·무급 기준은 이 값을 따른다.
- 직급이 `기원·기장·대리·과장·차장·부장`이거나 명칭이 `이사`로 끝나면 관리직, `조장·반장`이면 현장직(생산직)으로 자동 분류된다.
- `사원`은 관리직과 현장직이 혼재하므로 자동 변경하지 않고 직원별 선택값을 유지한다.
- 권한 부여·회수는 감사로그에 남으며 퇴직·비활성 계정은 권한을 사용할 수 없다.

## 8. 문의할 때 전달할 정보

문제 발생 시 비밀번호나 토큰을 제외하고 다음 정보를 전달한다.

- 사용자 이름과 부서
- 휴가계 또는 휴가 취소계 구분
- 문서번호 또는 원본 문서번호
- 대상 날짜와 휴가 종류
- 현재 문서 상태
- 화면에 표시된 오류 메시지
